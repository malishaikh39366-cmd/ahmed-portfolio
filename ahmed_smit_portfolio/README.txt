AHMED'S PERSONAL PORTFOLIO
Files:
- index.html (Home)
- about.html
- skills.html
- projects.html
- smit.html
- style.css

How to run:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html in your browser, or use Live Server.

Easy edits:
- Change the name "Ahmed" in the HTML files if needed.
- Change the A initials in the profile circles if you want.
- Edit the text in each page to match your real details.
- Skill progress bars are sample values; adjust them honestly.
- The SMIT page is a personal description, not an official SMIT page.

Bootstrap 5 is loaded from the official CDN, so an internet connection is needed for Bootstrap styling and the Google font.
